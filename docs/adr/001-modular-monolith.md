# ADR-001: 模块化单体（app + worker 同镜像不同命令）

日期：2026-08-16 · 状态：已接受

## 背景
平台需要 API 服务与异步长任务执行（解析入库、研究任务）。单人开发，部署面要小。

## 决策
FastAPI app 与 arq worker 共用同一代码库与镜像，以不同命令启动（uvicorn / arq）。
不拆微服务；服务边界只按故障域与依赖域切——GPU 解析是唯一例外（见 ADR-002）。

## 后果
- 共享 models / settings / 迁移，无跨服务契约维护成本
- app 与 worker 仍可独立扩缩（同镜像多副本不同命令）
- 出现真实的独立扩缩或团队边界需求时再拆
